# AI for Home Organizing

A beginner-friendly manual on using AI to organize your home: digital filing, photo routines, household inventories, family schedules, and printable labels.

Written plain English, step by step, like a friend would explain it. No condescension, no jargon without a definition, and privacy first — we never scan sensitive IDs.

## Who this is for

Anyone who wants a little help getting their household paperwork, photos, stuff, and schedules under control with AI. You do not need to be technical. If you can open a website or type a sentence into a chat box, you can use this guide.

## What's inside

- [`docs/`](docs/) — beginner manuals in Markdown
- [`site/`](site/) — the same manuals as a static HTML website you can open in any browser, print, or host anywhere
- Privacy-first guidance throughout, including a rule you will see on nearly every page: **never scan or upload sensitive IDs** (passports, driver's licenses, Social Security cards, birth certificates)

## How to read it

Start with [`docs/privacy.md`](docs/privacy.md), then pick a topic: digital filing, photos, inventories, schedules, or labels. The HTML site in `site/` works the same way — open `site/index.html` in your browser.

## Privacy promise

This guide is privacy-first and local-first where possible. We prefer tools that run on your own computer, and we never ask you to enter personal data, API keys, or secrets anywhere in these files. Nothing here should go into an AI chat unless you are comfortable with that provider seeing it.
