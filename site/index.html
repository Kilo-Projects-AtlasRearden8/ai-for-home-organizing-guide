Welcome

You do not need to be technical to use AI at home. If you can open a website and type a sentence, you can use everything in this manual.

This is a beginner-friendly guide to using AI to organize your home: digital filing, photo routines, household inventories, family schedules, and printable labels. It is written plain English, step by step, like a friend would explain it — never condescending.

Privacy first — read this before anything else. Never scan or upload sensitive IDs (passports, driver’s licenses, Social Security cards, birth certificates) to an AI. Start with Privacy First.

What’s inside

  • Getting Started — what AI is, how to prompt it, your first week

A simple way to start

Pick one small task this week:

  1. Ask AI to help you sort one drawer or shelf.
  2. Ask AI to plan three dinners using what is already in your fridge.
  3. Ask AI to write a one-page list of where your important papers live — without writing down account numbers.

Small wins build momentum. There is no wrong order. Start wherever feels most useful.
