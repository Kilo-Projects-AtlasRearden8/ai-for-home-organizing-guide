Digital Filing

Your computer probably has files everywhere: downloads, desktop, email attachments, and folders with names like final_v2_REALLYFINAL. AI can help you sort it out — without you having to become a filing clerk.

Step 1: See what you have

Open your main documents folder and take a screenshot, or ask AI to help you list what kinds of files you tend to save. You do not need to open every file.

“I have a messy Documents folder. What are the most common kinds of files families save, and what simple folders would hold them?”

Step 2: Make five folders (or fewer)

Keep it simple. Most households only need a handful of top-level folders:

  • House — lease or mortgage, utilities, home repairs, warranties
  • Money — taxes, bank statements, receipts, insurance
  • Family — school forms, medical summaries (no ID numbers), activity schedules
  • Personal — resumes, writing, hobbies, certificates you earned
  • Archive — old stuff you might need someday but do not use monthly

Create these folders, then drag files into the best fit. Do not aim for perfect. Aim for “I can find it in under a minute.”

Step 3: Name files so you can find them later

Good file names beat complicated folders. Use this pattern:

Year-Month-Day — Description — Version.ext

Examples:

  • 2026-03-14 — Electric Bill — January.pdf
  • 2026-01-20 — Tax Return — 2025.pdf
  • 2026-07-02 — Recipe — Chocolate Chip Cookies.pdf

Avoid spaces? Use hyphens. Avoid special characters like / \ : * ? " < > |.

Step 4: Let AI do the naming and sorting

If you have a list of messy file names, paste the list into AI (remove anything private first) and ask:

“Here are my messy file names. Rename them using the pattern Year-Month-Day — Description, and group them into folders. Keep descriptions short.”

AI cannot move your files for you, but it can give you a clean list to follow. Copy the new names and rename files in batches.

Step 5: Email and digital mail

For email, create two folders: Action (needs a reply or a task) and Reference (read later). File email the day you read it, or mark it unread so you do not forget.

For paper mail that arrives in your home, photograph or scan it once, file the PDF, then shred the paper if it contains no original signatures you must keep.

Privacy reminder: never file your passport, driver’s license, Social Security card, or birth certificate as a digital file you send to AI. Keep those physical, locked up, and out of any chat.

Quick checklist

  • [ ] Make 5 (or fewer) top-level folders
  • [ ] Name new files with Year-Month-Day — Description
  • [ ] File email daily into Action or Reference
  • [ ] Scan paper mail once, then decide: file or shred
  • [ ] No sensitive IDs in any digital file you share with AI
